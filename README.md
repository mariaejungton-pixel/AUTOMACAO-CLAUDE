# Imersão Automação na Prática

Site estático pronto para ser publicado como um **novo projeto** na Vercel.

## Conteúdo

- `index.html`: página principal da imersão.
- `inscricao/index.html`: formulário de inscrição.
- `vercel.json`: configuração de rotas e cabeçalhos.
- `.vercelignore`: impede o envio de arquivos desnecessários.

## Informações configuradas

- Data: 10 de outubro de 2026.
- Horário: a partir das 9h.
- Formato: online e ao vivo.
- Checkout: `https://pay.kiwify.com.br/SjoNQ28`.

## Publicar sem substituir o site antigo

1. Extraia o arquivo ZIP.
2. Entre na Vercel e escolha **Add New > Project**.
3. Crie um projeto novo; não selecione `vendas-era-tecnologica`.
4. Envie esta pasta por um repositório Git ou execute `vercel` dentro dela.
5. Confirme que a prévia está correta antes de promover para produção.

O pacote não contém `.vercel/project.json`, portanto não está vinculado ao projeto antigo.
